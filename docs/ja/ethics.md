# Change Coin の倫理規程

Change Coin は四つの原則の上に立つ。透明性、感情的知性、メンタルヘルスの脱スティグマ、そして粘り強さ。

利益は使命を支える。美徳が使命を定義する。人の価値は経済的価値に先立つ。人を実際に動かすのは関係だからだ。

目的は、過去の自分と未来の自分を含めて、人の全体を見ることだ。手厚い退職金のマッチは、未来の自分のため。療法へのアクセスを含む、心を中心に置いたケアは、過去の自分のため。現在は、人がどれほど複雑であるかへの共感だ。

ここに属する他の原則：脆弱さ、慈悲、そしてストア派の一組 — 知恵、正義、節制、勇気。

## 1. まず人間、それから従業員

誰もが従業員である前に人間である。苦難 — 心や体の病、悲しみ、危機 — には、圧力ではなく共感が向く。

- 必要なときの、有給で守られた休暇。回復は急がせない。
- 自分を世話しても、職は危うくならない。

## 2. 透明性

給与と報酬は社内で開かれている。秘密は競争を作る。開放は説明責任を作る。同じ規則が意思決定と倫理にも当たる。

## 3. 場所の自由

リモートを先にする。どこからでも働く。任意の共同スペース。出席の義務はない。

## 4. 原則のある利益

- 利益の 5% はメンタルヘルスの慈善団体へ。
- 倫理的な利益が不可能になったら、妥協するのではなく閉じる。

## 5. 経済的な健やかさ

過去、現在、未来。

- 市場を上回る 401(k) のマッチ。
- チームへの、続く個人財務の教育。
- 持分は、使命に合う形で提供できる。製品名は、取引できるコインの約束ではない。

金融リテラシーと経済的な安心は、メンタルヘルスの問題である。

## 6. 再生的な考え方

生きた系として運営する。行為は搾取するのではなく養う。提携は枯らすのではなく支える。人、共同体、環境を秤にかける。

## 7. 実践におけるストア派の徳

- 知恵：動く前に理解する。
- 勇気：難しいときに正しいことをする。
- 正義：公正と尊厳。
- 節制：成功のなかの均衡と謙遜。

私たちは完全ではない。振り返り、良くしていく。

Change Coin は、良いことをすることと、うまくやっていくことが同じであり得ることを示すために存在する。
