# Change Coin 伦理准则

Change Coin 建立在四项原则之上：透明、情商、去除心理健康的污名，以及坚持。

利润支撑使命。美德定义使命。人的价值先于经济价值，因为真正推动人的是关系。

目的是看见完整的人，包括过去的自己和未来的自己。慷慨的退休金配套是给未来的自己。以心为中心的照护，包括获得治疗的途径，是给过去的自己。当下是对人之复杂的同理。

这里还属于这些原则：脆弱、慈悲，以及斯多葛的一组——智慧、公正、节制、勇气。

## 1. 先是人，然后才是雇员

每个人在成为雇员之前都是人。困境——精神或身体疾病、哀伤、危机——得到的是同理，不是压力。

- 需要时给予带薪且受保护的休假。疗愈不被催促。
- 照顾自己不会让这份工作陷入危险。

## 2. 透明

薪酬与报酬在公司内部公开。保密制造竞争。公开制造问责。同一条规则适用于决策和伦理。

## 3. 地点的自由

远程优先。在任何地方工作。合作空间可选，不要求出勤。

## 4. 有原则的利润

- 利润的 5% 捐给心理健康慈善机构。
- 如果合乎伦理的利润变得不可能，就关闭，而不是妥协。

## 5. 财务上的安好

过去、现在和未来。

- 高于市场水平的 401(k) 配套。
- 为团队持续进行的个人理财教育。
- 股权可以按与使命相符的方式提供。产品名称不是对一种可交易硬币的承诺。

财务素养和财务安全是心理健康问题。

## 6. 再生式思考

作为一个生命系统来运转。行动应当滋养，而不是榨取。合作应当维持，而不是耗尽。权衡个人、社区和环境。

## 7. 实践中的斯多葛美德

- 智慧：先理解，再行动。
- 勇气：难的时候仍做对的事。
- 公正：公平与尊严。
- 节制：成功中的平衡与谦逊。

我们不会完美。我们会反省并改进。

Change Coin 的存在是为了表明：做好事与过得好可以是同一件事。
