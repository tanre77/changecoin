# ChangeCoin

Adult money clarity and wellness visits for iPhone and Android. ChangeCoin is a product name, not a cryptocurrency.

The running app is the Grok build. This branch marks the product home.

## What it includes

- An educational money dashboard in the spirit of a credit app. It is not a credit bureau score and does not ask for a Social Security number.
- A guide directory modeled on a teacher shelf: specialties, sit lengths, follow, and a free on-device timer.
- Licensed clinicians are labeled self-reported and unverified. Unlicensed people are wellness guides, out of pocket only, and cannot bill insurance.
- Apple Pay and Google Pay for real-world visits. This version does not mark a card as charged.
- Insurance upload keeps a plan name and the last four digits. The photo is not stored.
- Google Drive: list files and create a ChangeCoin folder.
- Practitioner mode on the same account, with an optional promoted listing.
- Video visits over WebRTC. Nothing is recorded.
- Firebase is wired for when a project is configured. Native Crashlytics attaches in the store binaries; the web app keeps the same crash log.
- One small labeled ad on Home and Money only.

Minimum clients: iOS 16 and Android 8.
