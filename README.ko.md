# ChangeCoin

어른을 위한 돈의 명확함과 웰니스 방문입니다. iPhone과 Android용입니다. ChangeCoin은 제품 이름이며 암호화폐가 아닙니다.

앱 소스 코드는 이 저장소에 있습니다. iPhone과 Android에 설치하는 웹 앱입니다.

## 앱에 포함된 것

- 신용 앱의 취지를 따른 교육용 돈 대시보드입니다. 신용평가기관의 점수가 아니며 Social Security 번호를 묻지 않습니다.
- 교사 선반을 본뜬 가이드 목록입니다. 전문 분야, 만남의 길이, 팔로우, 기기에서 쓰는 무료 타이머.
- 면허가 있는 임상가는 본인 신고이며 미확인으로 표시됩니다. 면허가 없는 사람은 웰니스 가이드이며, 본인 부담만 가능하고 보험 청구를 할 수 없습니다.
- 실제 방문에는 Apple Pay와 Google Pay를 씁니다. 이 버전은 카드를 결제됨으로 표시하지 않습니다.
- 보험 업로드는 플랜 이름과 끝 네 자리만 남깁니다. 사진은 저장하지 않습니다.
- Google Drive: 파일 목록을 보고 ChangeCoin 폴더를 만듭니다.
- 같은 계정의 실무자 모드. 선택적인 홍보 목록이 있습니다.
- WebRTC 영상 방문. 아무것도 녹화하지 않습니다.
- Firebase는 프로젝트가 구성되면 쓰도록 연결되어 있습니다. 네이티브 Crashlytics는 스토어 바이너리에 붙고, 웹 앱은 같은 비정상 종료 기록을 유지합니다.
- 작고 표시가 있는 광고는 Home과 Money에만 있습니다.

최소 클라이언트: iOS 16과 Android 8.
