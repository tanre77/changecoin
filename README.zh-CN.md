# ChangeCoin

面向成年人的金钱清晰度与健康拜访，适用于 iPhone 和 Android。ChangeCoin 是产品名称，不是加密货币。

应用源代码在本仓库中。它是可以安装在 iPhone 和 Android 上的 Web 应用。

## 应用包含的内容

- 一个教育性的金钱面板，思路接近信用类应用。它不是征信机构的评分，也不索取 Social Security 号码。
- 一个比照教师书架的向导目录：专长、会话时长、关注，以及设备上的免费计时器。
- 持证临床人员标注为自行申报且未经核实。无证人员是健康向导，仅自费，不能向保险收费。
- 使用 Apple Pay 和 Google Pay 支付现实中的拜访。此版本不会把卡片标为已扣款。
- 上传保险信息时保留计划名称和末四位数字。照片不予存储。
- Google Drive：列出文件并创建 ChangeCoin 文件夹。
- 同一账户上的从业者模式，以及可选的推广条目。
- 通过 WebRTC 进行视频拜访。不做任何录制。
- 已接入 Firebase，供项目完成配置后使用。原生 Crashlytics 附在商店二进制文件中；Web 应用保留同一份崩溃日志。
- 仅在 Home 和 Money 上有一条小型、带标识的广告。

最低客户端：iOS 16 和 Android 8。
