# ChangeCoin

Claridad sobre el dinero para adultos y visitas de bienestar en iPhone y Android. ChangeCoin es un nombre de producto, no una criptomoneda.

El código de la aplicación está en este repositorio. Es una aplicación web que se instala en iPhone y Android.

## Qué incluye la aplicación

- Un panel educativo sobre el dinero, en el espíritu de una aplicación de crédito. No es una puntuación de un buró de crédito y no pide un número de Social Security.
- Un directorio de guías inspirado en el estante de un docente: especialidades, duración de las sesiones, seguir y un temporizador gratuito en el dispositivo.
- Las personas clínicas con licencia aparecen etiquetadas como autodeclaradas y no verificadas. Las personas sin licencia son guías de bienestar, solo con pago particular, y no pueden facturar al seguro.
- Apple Pay y Google Pay para visitas en el mundo real. Esta versión no marca una tarjeta como cobrada.
- La carga del seguro conserva el nombre del plan y los últimos cuatro dígitos. La foto no se almacena.
- Google Drive: listar archivos y crear una carpeta de ChangeCoin.
- Modo de profesional en la misma cuenta, con una ficha promocionada opcional.
- Visitas por video mediante WebRTC. No se graba nada.
- Firebase está conectado para cuando se configure un proyecto. Crashlytics nativo se adjunta en los binarios de las tiendas; la aplicación web conserva el mismo registro de fallos.
- Un anuncio pequeño y etiquetado, solo en Home y Money.

Clientes mínimos: iOS 16 y Android 8.
