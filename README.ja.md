# ChangeCoin

大人向けの、お金の見通しとウェルネスの面談です。iPhone と Android 向け。ChangeCoin は製品名であり、暗号資産ではありません。

アプリのソースはこのリポジトリにあります。iPhone と Android にインストールできる Web アプリです。

## アプリに含まれるもの

- クレジット系アプリの考え方に沿った、教育用のお金ダッシュボード。信用情報機関のスコアではなく、Social Security 番号も求めません。
- 教師の棚を模したガイド一覧。専門分野、セッションの長さ、フォロー、端末上の無料タイマー。
- 免許を持つ臨床家は、自己申告であり未確認と表示されます。免許のない人はウェルネスのガイドで、自己負担のみ、保険請求はできません。
- 現実の面談には Apple Pay と Google Pay。この版では、カードを請求済みとは表示しません。
- 保険のアップロードでは、プラン名と末尾 4 桁だけを残します。写真は保存しません。
- Google Drive。ファイルの一覧と、ChangeCoin フォルダの作成。
- 同じアカウントの実践者モード。任意のプロモーション掲載があります。
- WebRTC によるビデオ面談。録画はしません。
- Firebase は、プロジェクトを設定したときに使えるよう接続してあります。ネイティブの Crashlytics はストア版バイナリに付きます。Web アプリは同じクラッシュログを保持します。
- 小さくラベルの付いた広告を、Home と Money だけに出します。

最小クライアント: iOS 16 と Android 8。
