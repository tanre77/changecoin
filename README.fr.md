# ChangeCoin

Clarté sur l'argent pour les adultes et visites de bien-être sur iPhone et Android. ChangeCoin est un nom de produit, pas une cryptomonnaie.

Le code source de l'application est dans ce dépôt. C'est une application web qui s'installe sur iPhone et Android.

## Ce que l'application comprend

- Un tableau de bord éducatif sur l'argent, dans l'esprit d'une application de crédit. Ce n'est pas un score de bureau de crédit et l'application ne demande pas de numéro de Social Security.
- Un annuaire de guides conçu comme l'étagère d'un enseignant : spécialités, durées de séance, suivi et un minuteur gratuit sur l'appareil.
- Les cliniciens titulaires d'une autorisation sont indiqués comme autodéclarés et non vérifiés. Les personnes sans autorisation sont des guides de bien-être, uniquement hors remboursement, et ne peuvent pas facturer une assurance.
- Apple Pay et Google Pay pour les visites dans le monde réel. Cette version ne marque pas une carte comme débitée.
- Le téléversement de l'assurance conserve le nom du régime et les quatre derniers chiffres. La photo n'est pas stockée.
- Google Drive : lister les fichiers et créer un dossier ChangeCoin.
- Mode praticien sur le même compte, avec une fiche mise en avant facultative.
- Visites vidéo via WebRTC. Rien n'est enregistré.
- Firebase est branché pour le moment où un projet est configuré. Crashlytics natif s'attache aux binaires des boutiques ; l'application web conserve le même journal de plantage.
- Une petite annonce identifiée, uniquement sur Home et Money.

Clients minimum : iOS 16 et Android 8.
