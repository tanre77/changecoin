# ChangeCoin

面向成年人的金錢清晰度與健康探訪，適用於 iPhone 與 Android。ChangeCoin 是產品名稱，不是加密貨幣。

應用程式原始碼在這個儲存庫。它是可以安裝在 iPhone 與 Android 上的 Web 應用程式。

## 應用程式包含的內容

- 一個教育性的金錢面板，概念接近信用類應用程式。它不是徵信機構的評分，也不索取 Social Security 號碼。
- 一個比照教師書架的引導目錄：專長、會談時長、關注，以及裝置上的免費計時器。
- 持證臨床人員標示為自行申報且未經查核。無證人員是健康引導者，僅自費，不能向保險收費。
- 使用 Apple Pay 與 Google Pay 支付現實中的探訪。此版本不會把卡片標為已扣款。
- 上傳保險資料時保留方案名稱與末四碼。照片不予儲存。
- Google Drive：列出檔案並建立 ChangeCoin 資料夾。
- 同一帳戶上的從業者模式，以及可選的推廣條目。
- 透過 WebRTC 進行視訊探訪。不做任何錄製。
- 已接上 Firebase，供專案完成設定後使用。原生 Crashlytics 附在商店二進位檔中；Web 應用程式保留同一份當機紀錄。
- 僅在 Home 與 Money 上有一則小型、有標示的廣告。

最低用戶端：iOS 16 與 Android 8。
